# MuleRun Agent 描述内容

## Overview（一句话总结，70字符以内）

```
将播客音频转换为结构化洞察报告，帮助用户快速理解播客核心内容
```

或者：

```
智能播客分析工具，自动提取播客核心观点和结构化总结
```

## Description（50-150字，完整说明）

```
Podcast to Insight 是一个专业的播客内容分析工具，能够自动处理小宇宙平台的播客音频，通过先进的语音识别（ASR）技术将音频转换为文字，然后使用 AI 生成结构化的洞察报告。

**核心功能：**
- 自动提取播客核心观点和关键信息
- 生成结构化的总结报告和大纲
- 支持中文播客内容分析
- 快速处理，通常在几分钟内完成

**适用场景：**
- 快速了解播客核心内容，节省时间
- 获取播客的结构化总结，便于回顾
- 提取关键观点，用于学习和研究

**注意事项：**
- 目前支持小宇宙平台的播客链接
- 处理时间取决于播客时长（通常 3-10 分钟）
- 每次查询消耗 100 credits
```

## Product Advantages（3-5个可量化的优势）

```
- **高效处理**：3-10 分钟完成播客分析，比手动收听节省 90% 时间
- **AI 驱动**：使用先进的语音识别和 AI 总结技术，准确提取核心观点
- **结构化输出**：生成清晰的总结报告和大纲，便于快速理解
- **即开即用**：无需注册，输入播客链接即可使用
- **专业分析**：针对中文播客内容优化，理解更准确
```

## Key Messages（一句话描述价值主张）

```
将播客音频转换为结构化洞察，让知识获取更高效
```

或者：

```
3 分钟读懂 1 小时播客，让学习更高效
```

## Prompts（1-3个提示词，遵循 "role + task + constraints + example" 结构）

### Prompt 1（基础使用）

```
你是一个播客内容分析助手。用户会提供一个小宇宙播客链接，你需要：
1. 分析播客内容
2. 提取核心观点
3. 生成结构化总结

示例输入：https://www.xiaoyuzhoufm.com/episode/xxxxx
示例输出：播客标题、作者、核心观点、总结报告
```

### Prompt 2（深度分析）

```
作为播客内容分析师，请对用户提供的播客进行深度分析：
- 提取 3-5 个核心观点
- 总结播客的主要论点和论据
- 生成便于回顾的结构化大纲

约束：分析要客观准确，避免主观判断
示例：输入播客链接，输出包含标题、作者、核心观点列表、详细总结的结构化报告
```

### Prompt 3（快速总结）

```
角色：播客内容总结助手
任务：快速提取播客核心内容
约束：总结在 500 字以内，突出重点
示例：输入播客链接，输出一句话总结 + 3 个关键点 + 详细总结
```
